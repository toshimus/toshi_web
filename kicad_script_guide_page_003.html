def pre_route_edge_shorts():
    board = pcbnew.GetBoard()
    j1 = board.FindFootprintByReference("J1")
    if not j1: return
    
    net_info = board.GetNetInfo()
    
    shorts = [
        (45, 46, "SOUND_IO", pcbnew.B_Cu),
        (48, 49, "CIRAM_CE", pcbnew.B_Cu)
    ]
    
    track_width = int(0.4 * 1000000)
    
    for p1, p2, netname, layer in shorts:
        net = net_info.GetNetItem(netname)
        if not net: continue
        
        pad1 = j1.FindPadByNumber(str(p1))
        pad2 = j1.FindPadByNumber(str(p2))
        
        if pad1 and pad2:
            pos1 = pad1.GetPosition()
            pos2 = pad2.GetPosition()
            
            top_y = pos1.y - int(5.5 * 1000000)
            
            pts = [
                pcbnew.VECTOR2I(pos1.x, pos1.y),
                pcbnew.VECTOR2I(pos1.x, top_y),
                pcbnew.VECTOR2I(pos2.x, top_y),
                pcbnew.VECTOR2I(pos2.x, pos2.y)
            ]
            
            for i in range(3):
                track = pcbnew.PCB_TRACK(board)
                track.SetStart(pts[i])
                track.SetEnd(pts[i+1])
                track.SetWidth(track_width)
                track.SetLayer(layer)
                track.SetNetCode(net.GetNetCode())
                board.Add(track)

def prepare_for_dsn_export():
    board = pcbnew.GetBoard()
    for track in list(board.GetTracks()):
        if not track.IsLocked():
            board.Remove(track)
            
    for zone in list(board.Zones()):
        board.Remove(zone)

【2段落】行ごとに詳しく説明

add_wiring_nets() 関数

ファミコンのカートリッジ特有のピンアサイン（配線情報）を定義し、各部品のパッド（端子）に論理的なネットワーク（ネット）を割り当てる関数です。

  • board.FindFootprintByReference("...") 配置済みの各部品（J1, U1, U2, R1, R2, SW1）をリファレンス名で検索し取得します。一つでも欠けている場合は安全のために処理を中断します（return）。
  • connections = [...] ネット名（例："GND"）と、そこに接続されるべき部品名・ピン番号のペアの巨大なリストです。VRAMのミラーリング切り替えスイッチ（SW1）やプルアップ抵抗など、カスタム基板としての緻密な配線が定義されています。
  • net_info = board.GetNetInfo() 基板のネット情報管理オブジェクトを取得します。
  • for net_name, pins in connections: 定義した配線リストを一つずつループ処理します。
  • net = net_info.GetNetItem(net_name) / if not net: ... 指定した名前のネットが既に存在するか確認し、存在しなければ pcbnew.NETINFO_ITEM を使って新しいネットを基板に登録します。
  • pad = u1.FindPadByNumber(pin_num) 等 リファレンス名に応じて、対象となる部品から特定のピン番号を持つパッドを検索します。
  • pad.SetNetCode(net.GetNetCode()) 見つかったパッドに対して、生成または取得したネットの内部ID（NetCode）を割り当てます。これにより、エディタ上で「未配線ライン（ラッツネスト）」が表示されるようになります。

pre_route_edge_shorts() 関数

オートルーターに任せず、エッジコネクタ上で物理的にショート（短絡）させるべき配線（SOUND_IOとCIRAM_CE）を、事前に銅箔パターンとして強制描画する関数です。

  • shorts = [...] J1の45番-46番ピン（SOUND_IO）と、48番-49番ピン（CIRAM_CE）をショートさせる設定です。裏面の銅箔層（pcbnew.B_Cu）を指定しています。
  • track_width = int(0.4 * 1000000) 配線の太さを0.4mm（KiCadの内部単位に変換）に設定します。
  • top_y = pos1.y - int(5.5 * 1000000) パッドの座標から5.5mm上（Y軸マイナス方向）の座標を計算し、U字型に配線を引き回すための頂点を決定しています。
  • pts = [...] ピン1の座標 → 5.5mm上の座標 → ピン2の真上の座標 → ピン2の座標という4つの頂点（3つの線分）をリスト化します。
  • track = pcbnew.PCB_TRACK(board) ... 3つの線分それぞれに対して実体のある銅箔トラックオブジェクトを生成し、幅、層、ネットコードを設定して基板（board）に追加します。

prepare_for_dsn_export() / build_all() 関数

  • prepare_for_dsn_export() 基板上のトラック（配線）をループし、IsLocked() で「ロック」されていない配線と、すべてのゾーン（塗りつぶし）を削除します。これはFreeRoutingなどのオートルーターに渡す前、不要な手動配線跡をクリーンアップするための処理です。
  • build_all() すべての関数を正しい順序で実行するメインルーチンです。注目すべきは、prepare_for_dsn_export() の後に pre_route_edge_shorts() が呼ばれている点です。これにより、意図的に描画したショート配線が削除されるのを防ぐ、見事な構成となっています。

【3段落】今回使用した公式APIの解説

論理的なネットワーク（回路）と物理的なトラック（銅箔）を操作するための主要なクラスとメソッドの解説です。

  • BOARD.GetNetInfo() / NETINFO_ITEM
    KiCadにおいて「どのピンとどのピンが繋がるべきか」という論理情報は、NETINFO_LIST と NETINFO_ITEM クラスで管理されています。スクリプトからネットを新規作成する場合は NETINFO_ITEM(board, "NetName") をインスタンス化し、board.Add() する必要があります。
  • FOOTPRINT.FindPadByNumber(pad_number_string)
    フットプリント内にある特定のパッドを、ピン番号（文字列形式）で検索して PAD オブジェクトを返します。
  • PAD.SetNetCode(code)
    物理的なパッドに対して、論理的なネット情報を紐付けます。引数には NETINFO_ITEM.GetNetCode() で取得した整数のIDを渡します。
  • pcbnew.PCB_TRACK(board)
    基板上に実際の銅箔配線（トラック）を描画するためのクラスです。始点、終点、レイヤー、幅、そしてどのネットに属しているか（SetNetCode）を個別に設定する必要があります。
  • BOARD.GetTracks() / TRACK.IsLocked()
    GetTracks() は基板上のすべてのトラックとビアを返します。IsLocked() は、ユーザーがプロパティで「ロック」を掛けた配線かどうかをブール値で返します。これを判定に使うことで、重要な配線だけを残して一括削除するといった制御が可能になります。
