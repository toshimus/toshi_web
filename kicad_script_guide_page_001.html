KiCad コンポーネント配置スクリプト ドキュメント

【1段落】オリジナルコード

def reset_board_components():
    board = pcbnew.GetBoard()
    for module in list(board.GetFootprints()):
        ref = module.GetReference()
        if ref in ["U1", "U2", "J1", "R1", "R2", "SW1"]:
            board.Delete(module)
    pcbnew.Refresh()
    print("基板上の既存コンポーネントをリセットしました。")

def place_components():
    board = pcbnew.GetBoard()
    
    base_path = None
    for version in ["10.0", "9.0", "8.0", "7.0"]:
        path = rf"C:\Program Files\KiCad\{version}\share\kicad\footprints"
        if os.path.exists(path):
            base_path = path
            break
            
    if not base_path:
        print("警告: フットプリントのパスが見つかりません。デフォルト設定を使用します。")
        base_path = r"C:\Program Files\KiCad\10.0\share\kicad\footprints"
        
    try:
        prg_path = os.path.join(base_path, "Package_DIP.pretty")
        
        prg_fp = pcbnew.FootprintLoad(prg_path, "DIP-32_W15.24mm")
        if prg_fp:
            prg_fp.SetReference("U1")
            prg_fp.SetValue("PRG_A29040B")
            prg_fp.SetOrientation(pcbnew.EDA_ANGLE(90, pcbnew.DEGREES_T))
            prg_fp.SetPosition(pcbnew.VECTOR2I_MM(56.82, 85))
            board.Add(prg_fp)
        
        chr_fp = pcbnew.FootprintLoad(prg_path, "DIP-32_W15.24mm")
        if chr_fp:
            chr_fp.SetReference("U2")
            chr_fp.SetValue("CHR_A29040B")
            chr_fp.SetOrientation(pcbnew.EDA_ANGLE(90, pcbnew.DEGREES_T))
            chr_fp.SetPosition(pcbnew.VECTOR2I_MM(107.62, 85))
            board.Add(chr_fp)

        res_fp_path = os.path.join(base_path, "Resistor_THT.pretty")
        for ref, pos in [("R1", (40.0, 75.0)), ("R2", (40.0, 85.0))]:
            r_fp = pcbnew.FootprintLoad(res_fp_path, "R_Axial_DIN0204_L3.6mm_D1.6mm_P7.62mm_Horizontal")
            if r_fp:
                r_fp.SetReference(ref)
                r_fp.SetValue("10K")
                r_fp.SetOrientation(pcbnew.EDA_ANGLE(0, pcbnew.DEGREES_T))
                r_fp.SetPosition(pcbnew.VECTOR2I_MM(pos[0], pos[1]))
                board.Add(r_fp)

        # VRAM A10切替スイッチ用のピンヘッダー（3ピン）を追加
        connector_path = os.path.join(base_path, "Connector_PinHeader_2.54mm.pretty")
        sw_fp = pcbnew.FootprintLoad(connector_path, "PinHeader_1x03_P2.54mm_Vertical")
        if sw_fp:
            sw_fp.SetReference("SW1")
            sw_fp.SetValue("VRAM_Switch")
            sw_fp.SetOrientation(pcbnew.EDA_ANGLE(0, pcbnew.DEGREES_T))
            sw_fp.SetPosition(pcbnew.VECTOR2I_MM(80.0, 115.0))
            board.Add(sw_fp)
            
    except Exception as e:
        print(f"部品配置中にエラーが発生しました: {e}")

【2段落】行ごとに詳しく説明

reset_board_components() 関数

  • def reset_board_components(): 基板上の特定部品を削除し、初期状態にリセットする関数の定義です。
  • board = pcbnew.GetBoard() 現在KiCadのpcbnewエディタで開かれている基板データを取得します。
  • for module in list(board.GetFootprints()): 基板上に配置されている全フットプリント（部品）のリストを取得し、1つずつループ処理します。
  • ref = module.GetReference() 現在ループしているフットプリントのリファレンス（U1、R1などの識別子）を取得します。
  • if ref in ["U1", "U2", "J1", "R1", "R2", "SW1"]: 取得したリファレンスが、削除対象として指定したリストの中にあるかどうかを判定します。
  • board.Delete(module) 判定が真（対象部品）であった場合、そのフットプリントを基板から削除します。
  • pcbnew.Refresh() 基板の描画状態を更新し、削除を画面上に反映させます。
  • print(...) コンソールにリセット完了のメッセージを出力します。

place_components() 関数

  • def place_components(): 新たに部品を配置する関数の定義です。
  • board = pcbnew.GetBoard() 再度、現在アクティブな基板データを取得します。
  • base_path = None フットプリントのライブラリが保存されている基本パスを格納する変数を初期化します。
  • for version in ["10.0", "9.0", "8.0", "7.0"]: KiCadの各バージョンのフォルダ名を新しい順にループ処理します。
  • path = rf"C:\Program Files\KiCad\{version}\share\kicad\footprints" Windows環境における、各バージョンの標準的なフットプリント格納パスを文字列として生成します。
  • if os.path.exists(path): 生成したパスが実際のPC上に存在するかどうかを確認します。
  • base_path = path / break パスが存在した場合、それを基本パスとして決定し、ループを終了します。
  • if not base_path: / print(...) / base_path = r"..." どのバージョンのパスも見つからなかった場合のフェイルセーフです。警告を出し、強制的に10.0のパスを設定します。
  • try: エラーが発生した場合にプログラムがクラッシュするのを防ぐため、例外処理を開始します。
  • prg_path = os.path.join(base_path, "Package_DIP.pretty") 基本パスにDIPパッケージ用のライブラリフォルダ名を結合し、正確なパスを作ります。
  • prg_fp = pcbnew.FootprintLoad(prg_path, "DIP-32_W15.24mm") 指定したライブラリから「DIP-32_W15.24mm」のフットプリントデータを読み込みます。
  • if prg_fp: フットプリントの読み込みに成功した場合のみ、以下の設定を行います。
  • prg_fp.SetReference("U1") この部品のリファレンスを「U1」に設定します。
  • prg_fp.SetValue("PRG_A29040B") この部品の値（型番や名称など）を「PRG_A29040B」に設定します。
  • prg_fp.SetOrientation(pcbnew.EDA_ANGLE(90, pcbnew.DEGREES_T)) 部品の角度を90度に回転させます。
  • prg_fp.SetPosition(pcbnew.VECTOR2I_MM(56.82, 85)) 部品のX・Y座標をミリメートル単位で指定し、位置を決定します。
  • board.Add(prg_fp) 設定を終えたフットプリントを、実際に基板上へ追加します。
  • ※以降の U2, R1, R2, SW1 のブロック 使用するライブラリパスや座標、設定値が異なるだけで、上記 U1 と全く同じ手順（ロード→参照・値設定→回転・座標設定→追加）を繰り返しています。
  • except Exception as e: / print(...) try ブロック内でパスの間違いやファイルの欠損などのエラーが起きた場合、その内容をコンソールに出力して処理を安全に終了します。

【3段落】今回使用した公式APIの解説

今回使用されたKiCad公式のPython API（pcbnewモジュール）の主要メソッドとクラスについての解説です。特にKiCad 7.0以降で刷新されたAPI構造に準拠しています。

  • pcbnew.GetBoard()
    現在pcbnewでアクティブになっている BOARD オブジェクト（基板全体を管理するクラス）のポインタを取得します。すべての操作の起点となります。
  • BOARD.GetFootprints()
    基板上に存在するすべてのフットプリント（FOOTPRINT オブジェクト）のイテラブル（反復可能なリスト）を返します。
  • BOARD.Delete(item)
    指定されたアイテム（この場合は FOOTPRINT）を BOARD オブジェクトの管理下から外し、メモリ上から削除します。
  • pcbnew.FootprintLoad(library_path, footprint_name)
    指定された .pretty フォルダ（ライブラリ）から、該当する名前のフットプリントを読み込み、新しい FOOTPRINT オブジェクトとしてインスタンス化して返します。見つからない場合は None を返します。
  • FOOTPRINT.SetReference() / SetValue()
    フットプリント内のテキストフィールドである「リファレンス（U1など）」と「値（10Kなど）」を書き換えます。
  • pcbnew.EDA_ANGLE(angle, unit)
    KiCad 7.0以降で導入された角度管理クラスです。以前のバージョンでは10分の1度単位の整数を直接渡していましたが、新しいAPIでは pcbnew.DEGREES_T（度）などの単位を明示的に指定してインスタンス化し、SetOrientation() に渡す必要があります。
  • pcbnew.VECTOR2I_MM(x, y)
    基板上の内部座標系（ナノメートル単位）を意識することなく、直感的にミリメートル（mm）単位の浮動小数点数で座標を指定し、正しい2Dベクトルオブジェクト（VECTOR2I）を生成するためのヘルパー関数です。これを SetPosition() に渡して配置位置を決定します。
